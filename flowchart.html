Function Breakdown & Interactions

readMeta(filePath) — home.php

Purpose: Loads metadata from a .meta file associated with an uploaded research paper.

Parameters:

  • $filePath: Full path to the uploaded document file

Returns: Associative array with keys: Title, Authors, Department, Adviser, Year, Category

How it works:

  • Sets default metadata values (Title=filename, others blank)
  • Constructs metadata file path by appending ".meta" to the document filename
  • If .meta file exists, reads lines and parses key=value pairs into the $meta array
  • Returns the populated metadata array to the caller

Called by: home.php's file scanning loop (line ~58)

Creates data used by: fileEntries array, HTML table rows

uploadfile() — submit.php

Purpose: Handles file upload, stores the document, and creates an accompanying metadata file.

Parameters: None (uses global $_FILES and $_POST)

Returns: Echo success/failure message to user

How it works:

  • Gets the temporary upload location from $_FILES['docFile']['tmp_name']
  • Gets the original filename from $_FILES['docFile']['name']
  • Uses move_uploaded_file() to move the temp file into FileFolder/
  • If successful, builds a metadata string from all POST form fields (Title, Authors, Department, etc.)
  • Saves the metadata string into a .meta file alongside the uploaded document
  • Outputs success message; otherwise outputs error message

Called by: submit.php bottom section (line ~262)

Interacts with: $_FILES, $_POST, FileFolder/ directory, .meta files

home.php — File Scanning & Filtering

Purpose: Builds and filters the file list based on user inputs (department, category, search term).

Key variables:

  • $selectedDepartment: From GET dept parameter (default: ALL)
  • $selectedCategory: From GET category parameter (default: empty)
  • $searchTerm: From GET search parameter (default: empty)
  • $fileEntries: Array of file data built from directory scan

Filtering flow:

  • Scans FileFolder/ directory, calls readMeta() for each file
  • Sorts files newest first by filemtime()
  • Filters by $selectedDepartment (if not ALL)
  • Filters by $selectedCategory (if selected)
  • Filters by $searchTerm (searches title, authors, department, category, filename)
  • Renders remaining files in HTML table

Data Flow: Upload → Storage → Display

Complete cycle:

  • User fills submit.php form and selects file
  • Form POSTs to submit.php, triggering uploadfile()
  • uploadfile() moves file to FileFolder/ and creates .meta file
  • User navigates to home.php or clicks a department button
  • home.php scans FileFolder/, calls readMeta() for each file
  • readMeta() parses the .meta file created by uploadfile()
  • Metadata populates the file table with Title, Authors, Department, Category, etc.
  • User can search, filter by department/category, or download the file
